## 📂 TECHNICAL DEEP DIVE (L'Anatomie du Code)

Pour les experts techniques, voici comment ce système génère de l'engagement :

### 🛠 Architecture & Neuro-Design
* **Temporal Binding Logic** : Un algorithme JS (`getHourIndex`) lie dynamiquement le contenu à l'heure réelle de l'utilisateur, créant un sentiment de "Moment Présent" (FOMO).
* **Immersive UI** : Utilisation d'effets de lueur (`.futuristic-glow`) et d'un mode sombre profond pour réduire la fatigue oculaire et augmenter le temps de session.
* **Accessibility features** : Intégration native de l'API `SpeechSynthesis` (TTS) pour une inclusion totale.
* **Local Storage Persistence** : Système de favoris persistant sans base de données, pour une expérience utilisateur fluide et privée.
